"친근한" "전문적인" 같은 키워드로는 실제 문장을 쓰기 어렵습니다. 브랜드 성격을 문장 기준으로 바꾸는 과정이 필요합니다.

02
문장 검수는
주관적으로 이루어지기 쉽다

"조금 더 부드럽게", "우리 서비스랑 안 맞는 것 같아요." 기준이 없으면 다시 수정할 때도 감에 의존하게 됩니다.
